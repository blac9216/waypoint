# Question template

Every question uses this shape. Blank lines between blocks are part of the template — the
owner reads it at a glance.

```markdown
**Round <R> · Question <x>/<N> · Category: <name> · Queued for next round: <k>**

**Previous Answer:** <one line: what the owner decided on the last question, as you
understood it — on the first round question, restate the setup answers (record location,
ceremony) instead>

| Newly queued follow-ups |          ← only when the previous answer produced one
|---|
| <the follow-up, one line> |

**<ID> — <question title>.** <the question, plain terms, one decision only; one or two
sentences of context if the owner needs it to answer>

- (a) **<option>** (recommended) — <why, briefly>
- (b) <option> — <trade-off>
- (c) <option> — <trade-off>
```

Setup questions (record location, ceremony) come before round 1 and carry no tally; they
still offer options with a recommendation.

Round opener (before question 1 of each round):

```markdown
**Round <R> — <N> questions**: <Category A> (<n>) · <Category B> (<n>) · …
```

Sidebar exit (before resuming the round):

```markdown
Sidebar closed: <one line: the resolution as recorded>. Resuming at <x>/<N>.
```
