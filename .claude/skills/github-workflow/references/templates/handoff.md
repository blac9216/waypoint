# Session Handoff Template

Chat only — the owner pastes it into the next session. Light on context: state is on
GitHub; this is what a new session needs to *start* without questions.

```markdown
## Handoff — <repo> — <UTC timestamp>
Target: <epic/milestone/issue> · Mode: <solo|serial|parallel> · Horizon: <…> · Claim: <id> (released|held)
main @ <sha>. Worktrees: <path> (<branch>, <state: clean | uncommitted WIP | PR open>) …
In flight: #<issue> → PR #<pr> → round <n> → next: <fix-round | fresh reviewer | cleanup>
Waiting on owner: #<issue> — <one line>
Next dispatch: #<issue>, #<issue> (why this order)
Gotchas this session: <one line each>
Log: <path> · Scratch: <path> · Brief: <last brief timestamp>
```
