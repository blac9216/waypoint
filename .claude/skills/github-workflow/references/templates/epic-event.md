# Epic Event Comment Template

Post on the epic when something happens to it: a child merges, a review finds something
worth remembering, a decision is taken, a claim is taken over, a validation run reports.
One event per comment; the thread is the log. Keep it to what a future session needs.

```markdown
### <landed | decided | found | validated | claim> — YYYY-MM-DD

**What**: #<issue> via PR #<pr> (round <n>) — one line.
**Drift from design**: none | <what changed and why>.
**Worth remembering**: <finding, gotcha, class of defect> | none.
**Next**: <what this unblocks or changes for open children>.
```
