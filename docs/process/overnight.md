# Overnight limits

Standing rules for unattended runs (owner rulings 2026-08-28):
- Lab access is **read-only**: scans, discovery, downloads, catalog pulls. No remediation, no configuration changes on lab systems, no credential rotation.
- Scope ceiling: work only issues already Ready under the claimed epic; do not open new epics or decompose new work — file and stop.
- Owner-gated decisions get `help` and are routed around; the morning brief lists them first.
- Public repository: the sanitization rule in AGENTS.md is absolute in every comment, issue and PR an agent writes overnight.
